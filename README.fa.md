## 📖 معرفی پروژه

**irpotify** یک اکوسیستم کامل، مدرن و خودمیزبان (Self-Hosted) برای نگهداری، مدیریت و پخش موزیک است. بر خلاف سرویس‌های شخص ثالث، تمامی فایل‌های صوتی، اطلاعات آلبوم‌ها و دیتابیس موسیقی شما روی سرور شخصی خودتان نگهداری شده و کنترل ۱۰۰٪ داده‌ها در اختیار شماست.

این پلتفرم شامل یک **اپلیکیشن بومی اندروید با طراحی بازنویسی‌شده کاملاً منطبق بر Spotify**، یک **پلیر ویندوز مستقل**، **داشبورد وب مدیریتی تحت React** و **ربات هوشمند تلگرام برای دریافت خودکار آهنگ‌ها** می‌باشد.

---

## ✨ قابلیت‌های کلیدی

- 🎧 **تجربه کاربری دقیقاً مشابه Spotify اورجینال:** چیپ‌های دسته‌بندی نوین در بالای صفحه خانه (`همه`، `آهنگ‌ها`، `آلبوم‌ها`، `هنرمندان`، `علاقه‌مندی‌ها`) و بخش کتابخانه مدرن با کارت پین‌شده «آهنگ‌های پسندیده‌شده (Liked Songs)».
- 📱 **ورود آنی با QR Code اختصاصی کاربر:** بدون نیاز به تایپ دستی آدرس سرور، نام کاربری یا پسورد؛ ادمین در پنل وب برای هر کاربر یک QR اختصاصی ایجاد کرده و با اسکن آن در اپ اندروید، کاربر در یک ثانیه وارد حساب خود می‌شود. همراه با امکان دانلود باکیفیت PNG، ارسال به تلگرام و واتس‌اپ با پیش‌نمایش غنی تصویر و کپی مستقیم به کلیپ‌بورد.
- 🎨 **هویت بصری و کاورهای واینیل اختصاصی:** بازطراحی کامل تجربه بصری با کاورهای واینیل وکتور واقعی (Realistic Vinyl Discs) و گرادیان‌های رنگی داینامیک برای قطعات بدون کاور، بنر استودیویی زنده در داشبورد با اکولایزر امواج صوتی و نشان‌های اختصاصی برای قطعات، آلبوم‌ها و شاخص‌های پایش.
- 📱 **ساخت پلی‌لیست‌های اختصاصی و محلی:** امکان ساخت، ویرایش و افزودن آهنگ به پلی‌لیست‌ها با ذخیره‌سازی ۱۰۰٪ محلی درون حافظه گوشی (Room Database) بدون هیچ وابستگی یا ترافیک سرور.
- 🚀 **نصب فوق‌سریع با یک دستور در لینوکس:** اسکریپت جادویی که داکر، دیتابیس PostgreSQL 17، ابزارهای صوتی و گواهی SSL رایگان را ظرف کمتر از ۲ دقیقه راه‌اندازی می‌کند.
- 🛠️ **ابزار مدیریت ترمینال (CLI):** بررسی وضعیت سرویس‌ها، مشاهده لاگ‌های زنده، ری‌استارت یا آپدیت سرور تنها با دستور `irpotify`.
- 🤖 **دریافت خودکار آهنگ از تلگرام با پشتیبانی از چند مدیر:** ارسال ساده فایل‌های صوتی به ربات اختصاصی سرور، استخراج خودکار متادیتا و کاور موزیک، با امکان تعریف چندین ادمین همزمان با جداکننده ``;`` (مانند `1234124;4324234`).
- ⚡ **هسته قدرتمند و بهینه:** توسعه‌یافته با ASP.NET Core (.NET 10) Minimal API، پایگاه داده PostgreSQL 17 و موتور صوتی ExoPlayer Media3 در اندروید.
- 🔒 **امنیت در سطح سازمانی:** ذخیره‌سازی امن توکن‌ها با Keystore اندروید، توکن‌های JWT چرخشی، فیلتر ضدبدافزار و دروازه امنیتی برای ادمین تلگرام.
- ⏳ **سیستم اشتراک و انقضای مبتنی بر ساعت معتبر سرور:** حذف محدودیت‌های سنتی حجم/زمان و جایگزینی با مدل شفاف تاریخ پایان اشتراک. سرور وضعیت دسترسی را منحصراً با ساعت سیستمی خود (`DateTimeOffset.UtcNow`) می‌سنجد؛ با رسیدن به تاریخ پایان، حساب کاربر فوراً دی‌اکتیو شده و از کلیه دستگاه‌ها (گوشی، ویندوز، وب) خارج می‌گردد. مدیران می‌توانند در هر زمان با پیش‌تنظیم‌های سریع ۱ ماهه، ۳ ماهه، ۶ ماهه یا ۱ ساله دوره جدیدی برای کاربر آغاز کنند.
- 🔐 **سیستم بدون بن‌بست بازیابی گذرواژه:** امکان بازیابی و تغییر گذرواژه حساب‌های کاربری با توکن راه‌اندازی سرور (Bootstrap Token) از وب یا مستقیماً از ترمینال سرور (`sudo irpotify reset-password`).

## 🚀 راهنمای سریع راه‌اندازی

### ۱. نصب سرور روی لینوکس (یک دستور خودکار)

#### 📋 پیش‌نیازها و آماده‌سازی سرور:
پیش از اجرای اسکریپت نصب روی اوبونتو، دبیان یا سایر توزیع‌ها، دستورات زیر را برای آپدیت بسته‌ها و باز کردن پورت‌ها اجرا کنید:

```bash
# ۱. به‌روزرسانی بسته‌های لینوکس
sudo apt update && sudo apt upgrade -y

# ۲. نصب ابزارهای موردنیاز اولیه
sudo apt install -y curl git ufw ca-certificates socat cron

# ۳. تنظیم پورت‌های استاندارد وب در فایروال (پورت‌های اختصاصی در زمان نصب خودکار تنظیم می‌شوند):
sudo ufw allow 80/tcp    # جهت صدور گواهی رایگان SSL Let's Encrypt
sudo ufw allow 443/tcp   # ترافیک امن HTTPS
```

#### ⚡ دستور نصب خودکار:
سپس تنها دستور زیر را در ترمینال سرور اجرا کنید:

```bash
curl -fsSL https://raw.githubusercontent.com/mohsenk2159/irpotify/main/install.sh | sudo bash
```

این اسکریپت به صورت ویزارد مرحله به مرحله موارد زیر را تنظیم می‌کند:
1. انتخاب پورت اختصاصی برای **داشبورد مدیریتی** (مثلاً `5080`).
2. انتخاب پورت اختصاصی برای **وب‌اپلیکیشن پلیر موسیقی** (مثلاً `5081`).
3. تنظیم حالت اتصال: دامنه اختصاصی با SSL خودکار رایگان یا اتصال مستقیم با IP سرور.
4. ساخت کلیدهای رمزنگاری امنیتی و تنظیم داکر و پایگاه داده PostgreSQL 17.
5. ایجاد ابزار خط فرمان اختصاصی `/usr/local/bin/irpotify`.

#### 🎛️ مدیریت سرور با ترمینال:
برای مدیریت سرور در هر زمان کافیست بنویسید:
```bash
sudo irpotify
```
یا از دستورات مستقیم استفاده کنید:
```bash
sudo irpotify status        # نمایش وضعیت کانتینرها
sudo irpotify logs          # مشاهده لاگ‌های زنده سرور
sudo irpotify restart       # راه‌اندازی مجدد سرویس‌ها
sudo irpotify update        # به‌روزرسانی سرور به آخرین نسخه گیت‌هاب
sudo irpotify ports         # تغییر پورت‌های داشبورد و وب‌اپ پلیر
sudo irpotify reset-db      # ریست دیتابیس (رفع خطای عدم تطابق رمز دیتابیس)
sudo irpotify credentials   # مشاهده اطلاعات و توکن راه‌اندازی
sudo irpotify reset-password # بازیابی و تغییر گذرواژه کاربر یا مدیر از ترمینال
sudo irpotify uninstall     # حذف کامل و پاکسازی سرور
```

> [!IMPORTANT]
> **نکته بسیار مهم برای استفاده در شبکه خانگی و محلی (LAN):**  
> اسکریپت نصب به صورت پیش‌فرض آدرس IP عمومی (اینترنتی) هاست را شناسایی می‌کند. اگر می‌خواهید از irpotify داخل شبکه محلی خانه یا شرکت (بدون دامنه اینترنتی) استفاده کنید تا گوشی، لپ‌تاپ و سایر دستگاه‌های متصل به همان وای‌فای به سرور وصل شوند، باید از **IP محلی سرور** (مانند `http://192.168.1.50:5080` به جای IP عمومی) برای اتصال در اپلیکیشن اندروید یا مرورگر استفاده کنید.  
> برای یافتن IP محلی سرور خود می‌توانید در ترمینال لینوکس دستور `hostname -I` یا `ip a` و در ویندوز دستور `ipconfig` را اجرا کنید.

### ۲. اتصال اپلیکیشن اندروید و ورود سریع با QR Code

1. فایل [**irpotify-android.apk**](https://github.com/mohsenk2159/irpotify/releases/download/v1.0.0/irpotify-android.apk) را روی گوشی خود نصب کنید.
2. **ورود فوری با اسکن QR Code (روش پیشنهادی و بدون دردسر):**
   - در پنل مدیریت وب وارد بخش **Users** شوید.
   - در ستون **Actions** کنار نام کاربر، روی آیکون **QR Code** کلیک کنید.
   - کادر پاپ‌آپ باز شده شامل کد QR اختصاصی کاربر و اطلاعات اتصال است. شما می‌توانید:
     - مستقیماً با دوربین گوشی و برنامه irpotify آن را اسکن کنید.
     - عکس باکیفیت را دانلود کنید (**دانلود تصویر**).
     - دکمه **ارسال تلگرام** یا **ارسال واتس‌اپ** را بزنید: تصویر QR Code بلافاصله در کامپیوتر دانلود شده، در حافظه کلیپ‌بورد کپی می‌شود (برای Paste کردن فوری با `Ctrl+V`) و صفحه چت با کارت پیش‌نمایش تصویر باز می‌شود.
   - اپلیکیشن اندروید با اسکن کد، تمام آدرس‌های شبکه (اینترنت و شبکه محلی)، نام دستگاه و احراز هویت را در یک ثانیه جایگذاری کرده و بدون نیاز به تایپ کلمه عبور وارد برنامه می‌شود!
3. **ورود دستی (نام کاربری و کلمه عبور):**
   - می‌توانید آدرس سرور را دستی وارد کنید.
   - *نکته شبکه محلی و وای‌فای:* اگر سرور و گوشی روی یک مودم یا وای‌فای مشترک هستند، از IP محلی سرور (مانند `http://192.168.1.xxx:5080`) استفاده کنید.

### ۳. نصب و راه‌اندازی اپلیکیشن آیفون و آیپد (iOS)

کلاینت iOS به صورت کاملاً بومی (Native) با **Swift و SwiftUI** طراحی شده و دارای قابلیت‌های پخش در پس‌زمینه (Background Audio)، کنترل لاک‌اسکرین و کنترل سنتر، و اسکن سریع QR کد است:

۱. **دانلود فایل برنامه:** فایل `irpotify-ios.ipa` را از [صفحه Releases در گیت‌هاب](https://github.com/mohsenk2159/irpotify/releases) دانلود کنید.
۲. **نصب با Sideloadly (پیشنهادی برای ویندوز و مک):**
   - برنامه رایگان [Sideloadly](https://sideloadly.io/) را روی کامپیوتر اجرا کنید و گوشی آیفون را با کابل USB متصل نمایید.
   - فایل `irpotify-ios.ipa` را کشیده و داخل پنجره برنامه رها کنید.
   - اپل آیدی معمولی خود را وارد کرده و دکمه **Start** را بزنید تا برنامه بدون نیاز به اکانت دلاری اپل نصب شود.
   - در گوشی وارد **Settings > General > VPN & Device Management** شوید و گواهی اپل آیدی خود را **Trust** کنید.
۳. **روش‌های جایگزین (AltStore یا TrollStore):**
   - در صورت استفاده از AltStore، فایل `.ipa` را با AltStore نصب نمایید.
   - در دستگاه‌های دارای TrollStore، فایل `.ipa` را باز کرده و با ترول‌استور به صورت دائمی (بدون انقضای ۷ روزه) نصب کنید.
۴. **ورود و اتصال سریع:** اپلیکیشن irpotify را در آیفون باز کرده و دکمه **Scan Server QR Code** را بزنید تا با اسکن کد QR داشبورد فوراً وارد شوید.

### ۴. راه‌اندازی ربات تلگرام برای آپلود موزیک (با پشتیبانی از چند مدیر)

برای اینکه بتوانید با فوروارد یا ارسال آهنگ به ربات تلگرام، آن را فوراً به سرور اضافه کنید:
1. در تلگرام به [@BotFather](https://t.me/BotFather) رفته و با ساخت ربات، **توکن ربات (Bot Token)** را دریافت کنید.
2. به ربات [@userinfobot](https://t.me/userinfobot) یک پیام بفرستید تا **شناسه عددی اکانت تلگرام شما (Id)** را به شما بدهد.
3. وارد داشبورد وب سرور شده و در بخش **Settings** → **Telegram**:
   - **توکن ربات** را وارد کنید.
   - **شناسه عددی ادمین تلگرام:** شناسه عددی خود را وارد کنید.
     > 💡 **پشتیبانی از چند ادمین:** اگر می‌خواهید ربات چند ادمین داشته باشد تا افراد مختلف بتوانند به آن آهنگ بفرستند و کنترلش کنند، شناسه‌های عددی آنها را با علامت ``;`` جدا کنید؛ برای مثال:  
     > `1234124;4324234;99887766`
   - گزینه **Ingestion** را فعال کرده و دکمه ذخیره را بزنید.
4. اکنون هر ادمینی آهنگ یا فایلی را به ربات بفرستد، بلافاصله پردازش شده و به کتابخانه سرور اضافه می‌شود!

### ۵. 🔐 بازیابی و تغییر گذرواژه

از آنجا که irpotify یک پلتفرم ابری شخصی و امن است و وابستگی به سرویس‌های ایمیل شخص‌ثالث ندارد، دو روش بدون نقص برای بازیابی حساب‌های کاربری در نظر گرفته شده است:

#### روش اول: از طریق صفحه ورود وب (بدون نیاز به دسترسی به سرور)
۱. در صفحه ورود داشبورد وب، روی گزینه **«فراموشی گذرواژه؟»** کلیک کنید.  
۲. **توکن راه‌اندازی (Bootstrap Token)** سرور را وارد کنید (این توکن هنگام نصب اولیه سرور در خط فرمان نمایش داده می‌شود و در فایل `.env` سرور نیز ذخیره است؛ همچنین با دستور `sudo irpotify credentials` در ترمینال قابل مشاهده است).  
۳. آدرس ایمیل حساب مورد نظر را وارد نمایید (در صورت خالی گذاشتن، حساب ادمین اصلی هدف قرار می‌گیرد).  
۴. گذرواژه جدید خود (حداقل ۱۲ نویسه) را وارد کرده و دکمه **بازنشانی گذرواژه** را بزنید.

#### روش دوم: از طریق ترمینال لینوکس (CLI)
اگر به ترمینال سرور دسترسی دارید، می‌توانید بدون نیاز به باز کردن مرورگر و با یک دستور رمز هر کاربری را بازنشانی کنید:
```bash
# به صورت تعاملی (درخواست ایمیل و گذرواژه جدید):
sudo irpotify reset-password

# یا با ارسال مستقیم مقادیر:
sudo irpotify reset-password admin@local MyNewPassword123!
```
همچنین می‌توانید با اجرای منوی مدیریت سرور `sudo irpotify`، **گزینه شماره ۸ (Reset Account Password)** را انتخاب کنید.

> [!NOTE]
> با هر بار تغییر گذرواژه، کلید امنیتی کاربر (`SecurityStamp`) تغییر یافته، تمام نشست‌ها و توکن‌های فعال قبلی به صورت خودکار لغو شده و قفل حساب بلافاصله برطرف می‌شود.
